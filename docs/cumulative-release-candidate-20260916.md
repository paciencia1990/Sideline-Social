## Ordinary-journey defects and repair status

The local source review found a concrete recovery defect: when a federated account had no private profile document, onboarding merged only completion fields and could leave required identity/default fields absent. That incomplete profile could prevent reliable public-profile projection and downstream name, friend, and team behavior. Password sign-up also performed its account/profile sequence outside the existing exclusive auth-operation guard.

The candidate now uses one canonical profile builder for new password accounts and genuinely missing-profile recovery. Recovery writes the complete private shape in a transaction; completion of an existing document merges only onboarding fields so relationships, team membership, and balances are preserved. Password sign-up now uses the exclusive auth-operation guard. The actual React Native local persistence adapter was extracted and directly tested without changing its LOCAL behavior.

The retained staging evidence does not prove that these source defects were the sole cause of every earlier phone symptom. Other possible causes are missing profiles for pre-existing test accounts, stale deployed social Functions or Rules/indexes, disabled staging auth providers, incorrect native OAuth/signing configuration, or missing team membership. This package does not fabricate those records or infer cloud state.
