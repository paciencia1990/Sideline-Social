   serialized operations, and removal only after confirmed server deletion.

   keyboard dismissal. Android fallbacks and Apple authorization remain intact.

   guards, shorter confirmed Trivia feedback, optional caller-only Bomb next
   view, and Spot tap feedback with stale-round protection.

   in Share/composer drafts; approved announcement links open with Retry.

8. Coach Mode recovery: visible Parent Mode escape and Retry, bounded strict
   current-team loading, independent archive failures and session-scoped mode.
9. Multi-sport Squads: creation checkboxes, all-sports venue labels and active
   manager editing, preserving Squad identity, membership, Teams and scores.
10. Admin member search: public-name filtering, 20-row results, Show more/Clear,
    preserved invitation/acceptance process and complete names beyond 250 members.

11. Home/Friends/chat efficiency: share overlapping reads, refresh Friend requests
    separately, load suggestions independently, pause offscreen Friends listeners,
    keep loaded Squad content visible during background refresh, count unread chats
    without public-profile hydration, and start independent message reads together.
    Account changes discard old responses; active membership and message visibility
    checks remain in force. See docs/app-efficiency-changes-20261010.txt.

12. Shared game-start preparation: readiness-count updates retain preparation for
    the current attempt; Retry is coalesced, superseded attempts cannot acknowledge
    or release gameplay, and the countdown ticker stops in gameplay/background.
13. Lobby/Bomb efficiency: account/Squad/filter-scoped refreshes coalesce, only
    visible foreground directories poll, room cards survive routine refresh, and
    Bomb reads coalesce with command/role/locale/account invalidation. Private
    Expert instructions remain caller-only and stale views are hidden.
14. Lobby backend: unchanged observations preserve stored timestamps; real room
    changes and expired entries reconcile, concurrent newer revisions survive.
    Rematch eligibility checks run in four bounded parallel workers while keeping
    current standing/membership, join order, capacity and host/rollback checks.
15. Teams/private-message efficiency: active Teams render independently of past
    counts; overlapping Team refreshes share a read; independent summary reads
    start together; unchanged hidden-message queries remain attached, with content
    withheld until every visibility chunk is ready. Read acknowledgements coalesce
    while the thread is visible. Public-profile reads share only in-flight work.
    See docs/game-and-team-efficiency-20261010.txt for validation and profiling.

16. Chat images: shared cache lookup/downloads, one in-memory manifest, nonblocking
    batched cache-access persistence, visible/viewer priority over nearby previews,
    scoped invalidation and cleanup barriers, stale-grant guards and explicit Retry
    after display failures. Existing protected byte/cache limits and server access
    checks are preserved. No additional backend or native dependency is needed.
    See docs/chat-image-loading-repair-20261010.txt for behavioral checks and the
    synthetic before/after operation comparison. Device timing awaits delivery.
