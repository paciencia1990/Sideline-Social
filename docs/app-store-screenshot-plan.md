# App Store Screenshot Plan

The first release is configured as **iPhone-only**, so no iPad screenshots should be uploaded. Before capture, confirm the current required iPhone display slot in App Store Connect. Prepare an opaque portrait master set at **1320 × 2868 pixels (6.9-inch iPhone)** and retain clean device captures so another accepted iPhone size can be exported if App Store Connect requests it.

## Privacy-safe demo setup

- Use fictional adult names, child names, teams, messages, venues, and Squad data.
- Do not show real email addresses, invite codes, private messages, precise coordinates, push tokens, or recognizable children.
- Disable debug banners, Metro/dev-client UI, local URLs, and test overlays.
- Use a production-like build and stable fictional accounts.

## Recommended sequence

1. **Parent Home** — compact Sideline Social header and core parent cards.
2. **Nearby Squads** — map/list with a fictional venue and generalized location context.
3. **My Teams** — private team hub and a fictional coach announcement; obscure the invite code.
4. **Coach Mode** — team management or coaching resources with fictional roster data.
5. **Weekly Challenge and Leaderboard** — show Sideline Stars and a privacy-safe Squad leaderboard.
6. **Games** — an actual Trivia Blitz or Spot the Difference screen from the submitted build.
7. **Spanish support** — one high-value screen in Spanish if space permits.

Use actual app screens. Marketing frames and captions may be added only if they remain factually accurate and do not conceal important UI. Check every final PNG for correct dimensions, opacity, spelling, safe-area rendering, and absence of private data.
