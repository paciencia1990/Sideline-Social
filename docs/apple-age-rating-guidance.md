# Apple Age-Rating Guidance

Status: **Owner/App Store Connect decision required.** Complete the questionnaire against the submitted binary and Apple’s then-current wording.

## Product positioning

Sideline Social is for parents, coaches, and other adults involved in youth sports. It should not be placed in Apple’s Kids Category. The presence of youth-sports and parent-managed child profiles does not make the account experience child-directed.

## Recommended questionnaire answers

| Capability | Recommended answer | Basis |
|---|---|---|
| Messaging/chat | Yes | Friend chat and private parent/coach team messaging |
| User-generated content | Yes | Messages, audio, announcements, replies, profile/team/Squad content |
| Social networking | Yes | Friends, Squads, teams, and communication |
| Blocking users | Yes | Friend-chat block enforcement and blocked-user management |
| Reporting content/users | Yes | Friend-chat and team-content reporting callables |
| Parental controls | No dedicated OS-style parental controls | Adults hold accounts; child profiles do not authenticate |
| Age assurance | No | No verified-age service is implemented |
| Location sharing | No public live-location sharing | Foreground location supports nearby discovery; venue locations appear on maps |
| Contests | No cash/prize contest found | Weekly Challenge and leaderboards award in-app Sideline Stars only |
| Simulated gambling | No | No wagering, casino, or chance-based gambling |
| Violence/mature themes | None expected | Verify final trivia/game content and assets |
| User-created audio | Yes | Private team voice messages |
| Unrestricted web access | No | Legal/support links open specific external pages only |
| Advertising | No | No ad SDK or advertising flow found |
| In-app purchases | No | No StoreKit or digital purchase flow found |

## Rating recommendation

Use the rating produced by Apple’s current questionnaire. Based on the audited social networking, chat, and UGC capabilities, plan for **13+ rather than an artificially low rating**, subject to the exact App Store Connect result and owner/legal review. If Apple’s questionnaire produces a higher rating, do not override it downward.

Before submission, confirm that all demo content, trivia, images, audio, and coaching resources match the answers above.
